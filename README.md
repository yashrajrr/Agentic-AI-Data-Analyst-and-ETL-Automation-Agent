## 🎯 Overview

**Agentic AI Data Agent** is an intelligent system that processes natural language queries and routes them to specialized agents for execution. The main agent acts as an intelligent router that understands user intent and delegates tasks to either the **SQL Analyst Agent** (for database queries) or the **ETL Analyst Agent** (for data extraction and transformation operations).

This project showcases modern AI engineering practices including:
- Multi-agent orchestration with LangGraph
- FastAPI backend serving a modern Tailwind CSS frontend
- Intelligent routing based on natural language understanding
- Tool-based agent architecture and dynamic LLM selection
- Safety validation for SQL queries to prevent destructive operations

---

## 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Data Agent (Router)                      │
│         Routes user queries to appropriate sub-agents       │
└────────────────────┬────────────────────────────────────────┘
                     │
         ┌───────────┴───────────┐
         │                       │
         ▼                       ▼
    ┌──────────────┐        ┌──────────────┐
    │ SQL Analyst  │        │ ETL Analyst  │
    │   Agent      │        │   Agent      │
    └──────────────┘        └──────────────┘
```

The system components:
1. **Frontend**: A modern Web Dashboard (HTML/JS + Tailwind) with tabs for Ask (Chat), Schema Viewer, My Files (ETL Output), and Query History.
2. **Backend**: FastAPI server (`api.py`) exposing REST endpoints for the UI.
3. **Agent Core**: LangGraph (`agents/data_agent.py`) state machines handling reasoning, tool execution, and result formatting.
4. **Database**: PostgreSQL storing the business ledgers.

## ✨ Features

### 🖥️ Modern Web Interface
- **Ask View**: Chat interface for querying the database or triggering ETL tasks in plain English.
- **Schema Viewer**: Live DB dictionary showing tables, columns, data types, and row counts.
- **My Files**: Browse and download outputs generated by the ETL agent.
- **Query History**: Audit log of past operations and generated code.
- **Dynamic Results**: Auto-renders SQL outputs as tables, with 1-click CSV download and copying.

### 🧠 Core Agent Capabilities
- **Intelligent Query Routing**: Automatically classifies user queries as SQL or ETL operations.
- **SQL Analysis Agent**:
  - Natural language to SQL query conversion.
  - Automatic schema context gathering and prompt construction.
  - SQL safety validation (blocks harmful operations like DROP, DELETE).
  - Intelligent query refinement and execution.
- **ETL Agent**:
  - API data extraction (JSON to structured formats).
  - Data transformation using Pandas.
  - Multi-format support (CSV, JSON, Parquet).
  - Dynamic, sandboxed code execution.
- **Multi-LLM Support**: Dynamically selects between cost-effective, balanced, and premium LLMs based on task complexity.

## 🚀 Installation

### 1. Clone and Setup Project

```bash
git clone <repository_url>
cd "ola data ai agent"
python -m venv .venv

# Activate virtual environment
# Windows:
.\.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
```

### 2. Install Dependencies

```bash
uv pip install -r requirements.txt
# or
pip install -r requirements.txt
```

### 3. Environment Configuration

Create a `.env` file in the root directory:

```env
# LLM Configuration
ANTHROPIC_API_KEY=your_claude_api_key
OPENAI_API_KEY=your_openai_api_key

# Database Configuration
host=localhost
port=5432
user=postgres
password=your_password
database=data_agent_db
```

### 4. Seed the Database

Run the interactive launcher to seed the initial data:
```bash
python main.py
# Select option [3] Initialize/Seed Database
```

## 💻 Usage

Start the system using the unified launcher:

```bash
python main.py
```

You will see an interactive menu:
```text
=== Data Agent Launcher ===
[1] Start API Server (Web UI)
[2] Run Agent CLI (Terminal)
[3] Initialize/Seed Database
[4] Exit
```

Select **[1]** to start the FastAPI server, then open your browser to `http://127.0.0.1:8000` to access the Data Agent dashboard.

## 🔐 Security Features

✅ **SQL Safety Validation**: Strict validation blocks `INSERT`, `UPDATE`, `DELETE`, `DROP`, and `ALTER` statements before they reach the database.
✅ **Read-Only Enforced**: UI operations flag as read-only mode to prevent accidental ledger tampering.
✅ **Safe Code Execution**: ETL Pandas transformations run in isolated executions.
✅ **XSS Protection**: Frontend escapes all dynamic inputs before rendering into the DOM.
